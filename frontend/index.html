What's actually running under the hood

Deterministic risk engine
Every failure is scored risk_score = failure_probability × amount × recovery_probability, blending payment-method and customer-level historical rates.
ML recovery model
Logistic regression, 5-fold cross-validated, never sees the simulator's hidden ground-truth label. Click Train recovery model below to see it evaluated live against a rule-based baseline.
Not yet trained this session
Expected-value strategy engine
7 candidate actions compared by expected value. STOP is always available at exactly ₹0 EV — a structural guarantee against a money-losing recommendation.
LLM agent (Groq) checking…
Tool-calling agent invoked only for genuinely ambiguous cases — never in the bulk automatic pipeline, by design.
Deterministic policy engine
8 independent guardrail checks combined with strict DENY > ESCALATE > ALLOW precedence. Neither the strategy engine nor the LLM agent can bypass it.
Fair experimentation
Every condition compared against the same transaction using the same random seed — real decision quality, not luck. Click Compare strategies below.
Performance engineering
Indexing, batched commits, and SQL-side aggregation replaced per-event commits — a measured 7x speedup, near-linear scaling past 20,000 transactions.
